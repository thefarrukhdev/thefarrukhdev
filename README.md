## 👋 About Me

I'm **Farrukh**, a **Frontend Developer & Software Engineer** from **Tashkent, Uzbekistan**. I turn product ideas into fast, polished, production-ready interfaces.

- ⚛️ **Frontend-first:** React, Next.js and TypeScript are my daily tools, with a focus on **reusable component architecture** and clean, scalable UI code.
- 🎨 **Design-minded:** responsive layouts, glassmorphism, and design systems built on Tailwind CSS, ShadCN UI and Radix UI.
- 🧠 **Engineering depth:** studying Software Engineering at **School 21 (42 Network)**, with peer-to-peer learning, algorithms, C/C++ and system programming.
- 🎓 **Training:** Frontend Development Program at **Najot Ta'lim**.
- 🔧 **Expanding to the backend:** Python, Node.js, NestJS, PostgreSQL and Redis, towards full-stack delivery.
